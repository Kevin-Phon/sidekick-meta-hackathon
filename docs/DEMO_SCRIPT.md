# Sidekick demo — target length 3 minutes

Record the real browser app; show actual results. Do not use an API key screen in the recording.

0:00–0:20 — Problem and purpose
“Sidekick is my AI work partner across school and projects. I want it to notice what changed, help me decide what matters, and prepare useful work without a separate prompt for every task.”

0:20–0:40 — Approved context
Show the four fictional saved sources. Explain these are file snapshots, not a live Gmail or Canvas connection. Briefly show the scope and model consent.

0:40–1:15 — Agent run
Show the real Muse Spark run: it compares context, proposes priorities across responsibilities, chooses up to two preparation actions, generates drafts, verifies current source state, and remembers the outcome. Open one project brief and one school draft if both were selected. Do not claim outputs the model did not create.

1:15–1:55 — Meaningful change
Apply the fictional update: practice deadline moves from November 5 noon to November 4 noon Pacific and a meeting requires an error-state demonstration. Run again. Show the before/after evidence and revised plan; compare to the original.

1:55–2:25 — Memory and progress
Mark a fictional step complete. Re-run and show that the model sees the saved progress and does not generate another action for a completed task. Re-run unchanged context: zero API calls, no duplicate outputs. Reload to show saved state remains.

2:25–2:45 — How Meta is used
Muse Spark generates a structured action plan and selected drafts. Local code enforces bounds, validates references, and atomically saves outputs only if sources/progress still match. Maximum three calls per run; no scheduled AI calls.

2:45–3:00 — Honest scope
“This event build adds the agent workflow to my earlier prototype. Live account connectors and continuous background observation are next. My current demo shows the core using explicitly approved snapshots.”

Record only behaviors actually verified. Leave margin under three minutes. Blur or omit personal content, credentials, billing and unrelated tabs.
